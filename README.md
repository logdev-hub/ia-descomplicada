# Inteligencia Artificial Descomplicada

Guia educacional introdutorio sobre IA e engenharia de prompts, com foco em aplicacao pratica no dia a dia.

## Objetivo do projeto

Oferecer um site completo para iniciantes aprenderem:

- Fundamentos de IA com explicacao simplificada
- Tecnicas de prompting com exemplos praticos
- Depuracao de prompts
- Construcao de prompts interativos com metatags
- Boas praticas de uso consciente da IA

## Estrutura por modulos

- Modulo 1: Fundamentos
- Modulo 2: Tecnicas de prompting
- Modulo 3: Laboratorios (gerador, debug e interativo avancado)
- Modulo 4: Uso consciente e aprofundamento
- Modulo 5: Quiz avaliativo e revisao final

## Paginas do site

- `index.html`: pagina principal com navegacao modular, tecnicas, laboratorios, quiz e resumo final
- `categoria-bases.html`
- `categoria-shots.html`
- `categoria-raciocinio.html`
- `categoria-controle.html`
- `categoria-qualidade.html`
- `categoria-interacao.html`
- `como-ia-funciona.html`: fundamentos de IA e estatistica
- `glossario-ia.html`: glossario com busca de termos

## Recursos implementados

- Navegacao responsiva organizada por modulos
- Biblioteca de tecnicas com filtros e busca
- Paginas por categoria com explicacao objetiva, desafios e aplicacao
- Botoes de copia para prompts
- Laboratorio rapido de prompts
- Debug de prompts com diagnostico e versao depurada
- Prompt interativo avancado com metatags e coleta de dados
- Quiz avaliativo (5 questoes) com correcao automatica
- Resumo dos pontos principais para revisao
- Blocos `Saida+` com orientacoes complementares

## Tecnologias utilizadas

## Como executar

1. Abra `index.html` no navegador.
2. Para melhor experiencia de desenvolvimento, use um servidor local (ex.: Live Server do VS Code).

## Observacoes para manutencao

- Todo o conteudo textual, variaveis e logica principal estao em PT-BR.
