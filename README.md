# Inteligencia Artificial Descomplicada

Guia educacional introdutorio sobre IA e engenharia de prompts, com foco em aplicacao prática no dia a dia.

## Objetivo do projeto

Oferecer um site completo para iniciantes aprenderem:

- Fundamentos de IA com explicacao simplificada
- Técnicas de prompting com exemplos praticos
- Depuracão de prompts
- Construcão de prompts interativos com metatags
- Boas práticas de uso consciente da IA

## Estrutura por modulos

- Modulo 1: Fundamentos
- Modulo 2: Técnicas de prompting
- Modulo 3: Laboratrios (gerador, debug e interativo avancado)
- Modulo 4: Uso consciente e aprofundamento
- Modulo 5: Quiz avaliativo e revisão final

## Paginas do site

- `index.html`: página principal com navegacao modular, técnicas, laboratrios, quiz e resumo final
- `categoria-bases.html`
- `categoria-shots.html`
- `categoria-raciocinio.html`
- `categoria-controle.html`
- `categoria-qualidade.html`
- `categoria-interacao.html`
- `como-ia-funciona.html`: fundamentos de IA e estatística
- `glossario-ia.html`: glossário com busca de termos

## Recursos implementados

- Navegacão responsiva organizada por módulos
- Biblioteca de técnicas com filtros e busca
- Páginas por categoria com explicação objetiva, desafios e aplicação
- Botões de copia para prompts
- Laboratório rapido de prompts
- Debug de prompts com diagnostico e versão depurada
- Prompt interativo avançado com metatags e coleta de dados
- Quiz avaliativo (5 questoes) com correção automática
- Resumo dos pontos principais para revisão
- Blocos `Saida+` com orientações complementares

## Tecnologias utilizadas

## Como executar

1. Abra `index.html` no navegador.
2. Para melhor experiência de desenvolvimento, use um servidor local (ex.: Live Server do VS Code).

## Observações para manutenção

- Todo o conteúdo textual, variáveis e lógica principal estao em PT-BR.
- Os exemplos priorizam cenários cotidianos para iniciantes.
- A navegacão foi unificada entre página principal e páginas internas.
